# 轻量化多人联机国麻（可运行 MVP）

这是一个**完整可运行**的多人联机麻将（国麻核心流程）示例项目，目标是快速验证玩法与联机。

## 已实现功能

- 4 人房间创建/加入
- 准备与开始对局
- 服务端发牌、摸牌、出牌（权威判定）
- 吃、碰、胡、过（弃牌后抢操作）
- 基础胡牌判定（标准 4 面子 + 1 对将）
- 流局判定（牌墙耗尽）
- 对局状态实时同步（Socket.IO）

> 说明：这是 MVP 版本，优先“能跑、能联机、能玩一整局核心流程”。

## 快速运行

```bash
npm install
npm start
```

启动后访问：

- http://localhost:3000

## 联机测试方式

1. 打开 4 个浏览器标签页（或 4 台设备）
2. 输入相同房间号（例如 `1001`）
3. 一人点击“创建房间”，其余人点击“加入房间”
4. 全员“准备”后，任意玩家点击“开始游戏”

## 项目结构

```text
.
├─ public/
│  └─ index.html        # 前端页面（房间、手牌、操作、日志）
├─ src/
│  └─ game.js           # 麻将牌与基础规则判定
├─ server.js            # Express + Socket.IO 游戏服务
└─ package.json
```
