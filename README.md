# twdaddy-home

家庭财务看板的静态网页版本，支持在浏览器内新增收入/支出记录，并自动汇总本月数据。

## 使用方式

1. 启动本地服务器：
   ```bash
   node server.js
   ```
2. 打开浏览器访问 `http://localhost:9000`。
3. 打开页面后输入密码 `0303` 进入看板（可在 `script.js` 中调整）。
4. 在“新增记录”中填写信息，数据将保存在服务器端的 `data.json` 中，供家庭成员共享。

## 常见问题

- **如何停止正在运行的服务器？**  
  在运行 `node server.js` 的终端窗口中按下 `Ctrl + C` 即可停止。
- **数据保存在哪个文件？**  
  所有记录都会保存在项目根目录的 `data.json` 文件中。

> 提示：`data.json` 会保存所有记录，可定期备份文件以避免丢失。
